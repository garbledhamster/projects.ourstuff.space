# Product

## Register

product

## Users

People managing multiple Ourstuff projects from a static dashboard. They need fast project selection, compact module status, and readable project details across desktop and mobile.

## Product Purpose

OurDashboard keeps project metadata, modules, readiness notes, and related project context in one local-first interface. Success means the user can select a project, inspect its current state, and update module details without the shell layout getting in the way.

## Brand Personality

Calm, practical, structured. The interface should feel like a reliable internal tool: readable, restrained, and direct.

## Anti-references

Avoid marketing-site composition, decorative dashboard cards, oversized hero typography, heavy gradients, and custom controls that obscure normal app behavior.

## Design Principles

- Keep the project selector and project body aligned as one app workspace.
- Let task panels scroll, not the whole page shell.
- Preserve dense information, but keep hierarchy and spacing scannable.
- Use familiar controls and restrained states over decorative novelty.
- Make mobile behavior intentional, especially when browser chrome and device bezels reduce usable height.

## Accessibility & Inclusion

Target WCAG AA contrast, visible focus states, keyboard-reachable controls, no content trapped behind fixed chrome, and reduced-motion-safe transitions.
